# Life Tracker PWA v2

Обновлённая версия с тёмным стеклянным дизайном и вкладкой мемов.

## Что нового

- современный тёмный интерфейс
- стеклянные карточки
- главный экран с кольцевым прогрессом
- улучшенная статистика
- отдельная вкладка "Мемы"

## Важно про мемы

В чистой PWA на GitHub Pages без собственного сервера надёжно и легально проще всего работать с Reddit.
Пикабу / VK / Telegram напрямую в браузерном приложении обычно упираются в CORS, авторизацию или ограничения сайтов.

Поэтому в этой версии вкладка мемов грузит случайные мемы с Reddit.

## Как обновить GitHub

1. Открой репозиторий `life-tracker`.
2. Замени файлы:
   - index.html
   - manifest.webmanifest
   - sw.js
   - папку icons
3. Закоммить изменения.
4. Подожди 1–2 минуты.
5. На iPhone обнови страницу, если нужно — закрой/открой PWA.

## Данные

Данные привычек и питания хранятся локально на устройстве.
Перед обновлением лучше сделать экспорт JSON из приложения.
