# Трекер привычек и питания — PWA для iPhone

Это веб-приложение, которое можно поставить на iPhone как иконку на экран Домой.

## Что внутри

- Привычки:
  - утренняя зарядка
  - велосипед, км
  - чтение книги
  - 2 литра воды
  - без сахара
  - без курения
  - без алкоголя
  - сон до цели
  - прогулка вечером

- Питание:
  - выбор продукта
  - граммовка
  - подсчёт калорий, белков, жиров, углеводов, клетчатки и сахара
  - база продуктов, включая яйцо варёное, брокколи, цветную капусту

- Статистика
- Настройки
- Экспорт/импорт JSON

## Как запустить через GitHub Pages

1. Создай новый репозиторий на GitHub, например `life-tracker`.
2. Загрузи в него все файлы из этой папки:
   - index.html
   - manifest.webmanifest
   - sw.js
   - папку icons
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Сохрани.
6. Через минуту GitHub даст ссылку вида:
   `https://username.github.io/life-tracker/`

## Как добавить на iPhone

1. Открой ссылку в Safari.
2. Нажми кнопку «Поделиться».
3. Выбери «На экран Домой».
4. Нажми «Добавить».

## Важно

Данные хранятся локально в браузере iPhone через localStorage.
Чтобы не потерять данные, иногда делай экспорт JSON в разделе настроек.
